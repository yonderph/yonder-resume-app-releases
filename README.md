# yonder-resume-app-releases

Installers for Yonder Resume. The app updates itself from here.

## Install notes

### Windows

Download `YonderResumeSetup.exe` from the latest release and run it. The installer is not
code-signed yet, so Windows SmartScreen may warn you the first time. Choose **More info**, then
**Run anyway**. After that, the app updates itself.

### Mac (Apple Silicon)

Download `YonderResume.dmg`, open it and drag Yonder Resume to Applications. The first time you
open the app, macOS will block it. Go to **System Settings › Privacy & Security** and choose
**Open Anyway**. Mac copies don't update themselves yet, so download the new `.dmg` for each
release. Intel Macs aren't supported yet.
